# Kosas Checkout Skin Demo

PayPhi-style cart/checkout drawer skin for **Kosas** (Revealer Skin-Improving Foundation SPF 25).

## Stack
- React + Vite
- Founders Grotesk Medium
- Official Kosas logo
- Shared checkout flow: shipping / delivery / payment, drawer loader, card brand logos

## Run
```bash
npm install
npm run dev
```

Promo code: `KOSAS10`
